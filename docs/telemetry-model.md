# OpenTelemetry & Telemetry Data Model

The Agent Reliability Platform follows standard OpenTelemetry conventions while introducing structured `arp.*` namespacing to model AI agents and tools without attribute collisions.

---

## 1. Standard OpenTelemetry GenAI Semantic Conventions

| Attribute Key | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `gen_ai.system` | string | LLM provider or platform | `openai`, `anthropic`, `google` |
| `gen_ai.request.model` | string | Requested model identifier | `gpt-4o`, `claude-3-5-sonnet-20241022` |
| `gen_ai.response.model` | string | Actual served model identifier | `gpt-4o-2024-08-06` |
| `gen_ai.operation.name` | string | Operation category | `chat`, `generate`, `embed` |
| `gen_ai.usage.input_tokens` | integer | Tokens consumed by input prompt | `1450` |
| `gen_ai.usage.output_tokens` | integer | Tokens generated by completion | `320` |
| `gen_ai.response.finish_reason` | string | Reason model stopped generating | `stop`, `tool_calls`, `length` |

---

## 2. ARP Namespaced Attributes (`arp.*`)

| Attribute Key | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `arp.span.type` | string | Span classification | `agent`, `llm`, `tool`, `retrieval`, `embedding` |
| `arp.run.id` | string | Agent workflow correlation ID | `run_4511b031...` |
| `arp.agent.name` | string | Registered agent name | `customer_support` |
| `arp.agent.version` | string | Semantic agent version | `1.4.2` |
| `arp.prompt.version` | string | Prompt template version | `v2.1` |
| `arp.tool.name` | string | Target tool identifier | `crm.lookup_customer` |
| `arp.tool.call_id` | string | Tool execution call ID | `call_9821` |
| `arp.tool.status` | string | Tool execution state | `ok`, `failed` |
| `arp.tool.retry_count` | integer | Number of preceding attempts | `2` |
| `arp.tool.error_type` | string | Normalized error taxonomy | `timeout`, `validation_error`, `rate_limit` |
| `arp.cost.usd` | float | Exact calculated spend | `0.006825` |

---

## 3. Tool Error Taxonomy

ARP categorizes tool errors deterministically:
* `validation_error`: Input arguments failed schema validation or bad query syntax.
* `timeout`: Downstream tool execution exceeded time limit.
* `unavailable`: Downstream service unreachable or 503 error.
* `authentication_error`: API key rejected, token expired, or unauthorized 401/403.
* `rate_limit`: HTTP 429 or provider throughput throttling.
* `provider_error`: Upstream model gateway failure.
* `application_error`: General unhandled execution exception.
* `unknown`: Unclassified failure.
